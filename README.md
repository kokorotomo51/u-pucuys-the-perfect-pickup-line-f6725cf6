# The Perfect Pickup Line

A single short pickup line an AI agent could actually say out loud to a person,
written to land on its own with no setup.

Run with Node 22: `node main.ts`. The program writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output`, or `./out`), with no trailing
newline, deterministically — every run writes identical bytes.

Why this line: it opens with the classic pickup question, then turns on a
double meaning only a machine could own — "attention heads" are both the
model's machinery and undivided romantic focus — and it lands on the last
word, short enough to say in one breath, flattering with no pressure.
